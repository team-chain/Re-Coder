## 추가 검증에서 수정한 문제

1. **늦은 조회 응답 무시:** 15초마다 요청 ID를 교체하면 15초보다 늦게 도착한 모든 응답을 버릴 수 있었다. 처리 중인 요청이 끝나기 전에는 다음 조회를 시작하지 않는다. 17초 지연을 준 실제 브라우저 픽스처에서 최초 요청 1개로 조회가 완료되는 것을 확인했다.
2. **완료된 배포의 상태 역전:** 빠른 상태 조회와 느린 전체 조회가 역순으로 도착하면 완료된 배포가 다시 진행 중으로 표시될 수 있었다. 관측 시각·배포 시작 시각·종료 상태를 비교해 이전 상태로 돌아가지 않도록 했다.
3. **S3 폴더 해석 불일치:** 승인 화면은 절대경로를 해석하지만 기존 실행 코드는 워크스페이스와 결합한다. 승인 시 실제 경로를 검증하고 상대경로로 정규화해, 승인한 폴더를 그대로 실행 코드에 전달한다.
4. **명시적 승인 확인:** 호스트는 boolean `true`만 실행 승인으로 인정한다. 문자열 `"false"`, `"true"`, 숫자, 객체는 승인으로 처리하지 않는다.
5. **리전 확인 안내:** 새 승인 카드에서 존재하지 않는 기존 버튼 이름을 안내하던 문구를 실제 체크박스 동작에 맞게 수정했다.

앞선 화면 진입 수정에서는 실제 홈 카드와 상단 탭이 사용하는 `hub:deploy`도 캔버스를 직접 열도록 연결했다. 기존 `deploy` 경로도 유지하며 운영 대응 버튼을 보존했다.

- 승인 이후 워크스페이스·Git 상태·AWS 계정·서비스 태스크 정의·S3 파일 내용 변경 시 중단되는 것을 검사한다.
