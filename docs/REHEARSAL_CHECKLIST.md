# ReCoder 배포 전 리허설 체크리스트 (클린 PC)

> 목적: 학생이 받게 될 그대로의 VSIX를, ReCoder가 깔린 적 없는 환경에서 끝까지 한 번 돌려본다.
> 하나라도 막히면 그 자리에서 고치고 다시 한다.

## 0. 사전
- [ ] `recoder.gateway.url` 기본값이 **실제 배포 URL**로 박힌 VSIX인가
- [ ] (코드 에이전트/스캔 쓸 거면) 번들 `bin/recoder-core.exe` 가 **최신 Core**로 재빌드됐는가
- [ ] 게이트웨이가 살아있고 반 코드/정원이 설정돼 있는가

## 1. 설치 & 기동
- [ ] Install from VSIX → VSCode 재시작
- [ ] ReCoder 아이콘 + 사이드바(Re-Coder / Workbench 뷰) 표시
- [ ] Core 자동 spawn 성공 ("준비됨" 상태) — 수동 시작 없이

## 2. 연결 (enroll)
- [ ] 최초 반 코드 입력창 등장(또는 명령으로 실행)
- [ ] 올바른 코드 → "연결 완료", student_id 발급
- [ ] 잘못된 코드 → 친절한 거부 메시지

## 3. Build — 에러 수정(자동)
- [ ] 터미널에서 일부러 에러 내기 → 자동 감지로 분석/수정안 제안
- [ ] 패치 적용/거절 동작

## 4. Build — 코드 생성 에이전트
- [ ] "할 일 목록 앱…" 생성 → ops 카드 표시 → 적용 시 파일 생성 + 에디터 열림
- [ ] EDIT op에서 "변경 보기"(diff) 동작
- [ ] 이어서 "더 빠르게 해줘"(멀티턴) → 같은 파일 수정으로 반영
- [ ] 일부러 키 박힌 요청 → ⚠ 시크릿 경고 표시

## 5. 시크릿 스캔
- [ ] 프로젝트 곳곳(다른 파일)에 가짜 키 심기 → 스캔이 파일:라인까지 잡고 값은 마스킹

## 6. (선택) Discord
- [ ] 워크벤치 Discord 탭에서 봇 초대
- [ ] `/recoder link <id>` 바인딩
- [ ] `/make …` → 해당 학생 VSCode에만 생성(격리 확인)

## 7. 비용/한도
- [ ] 사용량 % 푸터 표시
- [ ] 쿼터 초과 시 차단 메시지

## 8. 정리
- [ ] 발견된 이슈 목록화 + 수정 → 재리허설
