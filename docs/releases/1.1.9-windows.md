# ReCoder 1.1.9 — 소스 구조 탐색 배율 유지

배포 아키텍처에서 프로젝트를 클릭하면 파일 관계, 파일을 클릭하면 함수 관계로 들어가는 기존 동작을 유지합니다.

이전에는 배포 화면만 높이에 맞춰 캔버스 폭을 제한하고, 소스 구조 화면은 전체 가로폭을 사용했습니다. 1280×720 브라우저에서 클릭 직후 캔버스 폭이 848.23px에서 1183.33px로 바뀌는 것을 재현했습니다.

모든 탐색 단계가 배포 화면과 같은 기준 크기를 사용하도록 수정했습니다. 파일 수나 검색 결과가 바뀌어도 표시 배율은 유지하며, 큰 구조는 스크롤로 탐색합니다. 사용자가 선택한 확대 배율도 파일·함수 진입과 배포 화면 복귀 후 유지합니다.

## 검증

- TypeScript 호스트·웹뷰 검사 및 프로덕션 webpack 빌드 통과.
- 기존 캔버스·드래그·3D·승인 회귀 검사 22개 통과.
- 실제 프로덕션 웹뷰 번들과 확장 호스트의 로컬 분석기로 프로젝트 → 파일 → 함수 → 배포 복귀 확인.
- 기본 배율에서 클릭 전후 폭 848.23px 유지. 직접 확대 후 975.47px 유지.
- 26개 파일 구조, 파일 검색, 단일 함수 진입에서도 배율 유지. 맞춤 버튼으로 기본 배율 복귀.
- Three.js 및 SVG 대체 렌더러에서 동일 배율 확인. 프로젝트를 Docker 노드에 드래그하여 Docker 패널 진입 확인.
- VSIX 내부 웹뷰·확장 호스트·Core 파일과 빌드 결과의 일치 및 내장 Core self-check 확인.
- Python이 PATH에 없는 격리 프로필에서 패키지 실행 검사 통과: Core 자동 시작·세션 인증·프로젝트/파일 분석·미인증 대상 차단·배포 계획 취소·재시작·종료.

이번 변경은 캔버스 표시와 탐색에 한정됩니다. 외부 AWS 배포·GitHub 푸시·Discord 전송은 이번 검증에서 실행하지 않았습니다.
