# ReCoder 1.1.1 — GitHub·Discord 수정본

설치 파일: `extension/dist/recoder-1.1.1-win32-x64.vsix`.

## 설치

1. VS Code 확장 화면 → `…` → **Install from VSIX…**에서 1.1.1 파일을 선택합니다.
2. VS Code를 다시 로드하고 확장 버전이 **1.1.1**인지 확인합니다.
3. `ReCoder: Restart Core`를 실행해 동봉한 새 Core를 사용합니다.
4. 테스트할 프로젝트 폴더를 열고 `ReCoder: Open Workspace` → Deploy로 이동합니다.

## GitHub

1. 프로젝트를 GitHub에 끌어 놓거나 GitHub 아이콘을 누릅니다.
2. **GitHub 로그인**을 누르고 VS Code의 인증 안내를 완료합니다. 계정 이름과 저장소 선택이 표시됩니다.
3. 기존 저장소를 선택하거나 주소를 입력합니다. 새 프로젝트라면 **새 비공개 저장소**를 선택해 이름을 입력하고 연결합니다. 연결 단계에서 파일은 업로드되지 않습니다.
4. 첫 커밋이 없으면 **소스 제어에서 커밋**을 눌러 올릴 파일을 확인하고 커밋합니다. 돌아와 **상태 새로고침**을 누릅니다.
5. **푸시 내용 확인** → 저장소·브랜치·커밋 확인 → **승인하고 푸시**를 누릅니다.

미커밋 변경은 포함되지 않으며 강제 푸시는 하지 않습니다. 기존 origin은 자동 교체하지 않습니다.
이미 이력이 있는 원격 저장소와 충돌하면 Git에서 이력을 정리한 후 다시 승인해야 합니다.
Git이 설치되어 있어야 하며, 시크릿 검사가 실행되지 않거나 탐지 결과가 있으면 업로드를 중단합니다.

## Discord

1. 연결 여부에 관계없이 캔버스의 Discord 아이콘이 보여야 합니다.
2. 아이콘을 눌러 연결 화면을 엽니다. Discord는 알림 채널이므로 프로젝트를 배포할 대상이 아닙니다.
3. ReCoder Discord 봇 서버가 필요합니다. VSIX에는 Core가 포함되어 있지만 Discord 봇 서버는 별도입니다.
4. **봇 서버 연결 설정**에서 `recoder.bridge.host`, `recoder.bridge.httpPort`, 필요한 경우 `recoder.bridge.registrationKey`를 확인합니다. 기본 HTTP 주소는 `127.0.0.1:8765`입니다.
5. 봇 서버를 실행하고 **다시 연결** → 서버 선택 → 채널 선택 → **선택한 채널 연결**을 누릅니다.
6. 알림 체크박스를 켜면 이후 화면에서 관측한 새 이벤트만 전송합니다. 켜기 전의 이력을 소급 전송하지 않습니다.

## 검증 범위

로컬 Git 저장소 생성·첫 커밋 전후 상태, 기존 origin 보존, OAuth 취소 응답, AWS 없이 GitHub 승인 준비, 시크릿 검사 실패 차단, SSH 주소 해석, 인증 없는 푸시 오류를 자동 검증합니다.
Discord는 로컬 HTTP 테스트 서버에서 상태 조회·서버/채널 선택·연결·알림 동의 조건을 검증하고, 실제 React/Three.js 화면에서 오프라인과 연결 전후를 확인합니다.
실제 사용자 GitHub 저장소 생성/업로드나 Discord 채널 메시지 전송은 수행하지 않습니다.

- Core 전체 회귀: 1,845 통과, 3 건너뜀. 이후 프론트엔드 Docker·GitHub·인프라 생성 변경 관련 98개 추가/재검증 통과.
- 확장 회귀: 368 통과, 2 건너뜀.
- 최종 VSIX: 별도 Python이 없는 격리 사용자 환경에서 동봉 Core 1.1.1 실행, 세션 인증, 소스 분석, GitHub 미인증 오류, Core 재시작·완전 종료 및 파일 해시 검증 통과.
- 테스트 프로젝트: Windows 프로덕션 빌드 및 Linux Docker 이미지 빌드 성공. 컨테이너 `healthy`, 실행 사용자 101, `/health`·루트·SPA 경로·JS·CSS 모두 HTTP 200.
- 브라우저: Docker에서 게시판 표시, 작성·수정 및 새로고침 후 저장 유지 확인. 삭제 확인창 표시까지 확인했으며 확인창 이후 삭제 완료는 자동화 도구의 응답 제한으로 검증하지 못했습니다.
