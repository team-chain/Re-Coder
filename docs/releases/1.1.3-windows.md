# ReCoder 1.1.3 — 왼쪽 Activity Bar 진입점

## 설치 및 실행

1. VS Code의 확장 화면에서 **… → Install from VSIX…**를 선택하고 `recoder-1.1.3-win32-x64.vsix`를 설치합니다.
2. **Developer: Reload Window**를 실행합니다. F5 개발 호스트를 사용 중이었다면 먼저 디버깅을 종료하고 일반 VS Code 창에서 설치합니다.
3. 왼쪽 Activity Bar의 **테두리 안 R 아이콘**을 누릅니다. 가운데 ReCoder 작업 화면이 열립니다.
4. 다른 파일로 이동한 뒤 R 아이콘을 다시 눌러 ReCoder로 돌아올 수 있습니다.

이전 버전이 저장한 ReCoder 뷰 위치는 업데이트 후 한 번 복원합니다. Explorer 등 다른 확장 화면의 배치는 초기화하지 않습니다. 기존 Workbench는 ReCoder 컨테이너의 보기 메뉴에서 열 수 있습니다.

Activity Bar 자체를 숨겨 둔 경우에는 **View → Appearance → Activity Bar Position → Default**로 표시합니다. 이후 사용자가 아이콘을 직접 숨기거나 옮긴 경우에는 해당 사용자 설정을 따릅니다.

## 변경 범위

- ReCoder 전용 Activity Bar 컨테이너와 24px R 아이콘.
- 첫 실행 때 오른쪽 사이드바로 옮기던 코드 제거.
- 기존 설치의 ReCoder 뷰 위치를 복원하는 일회성 마이그레이션.
- 재진입 시 이미 열린 ReCoder 패널로 돌아가고 포커스를 전달.
- Core는 버전 표기만 변경했습니다. 1.1.2의 개발·배포·보안 검사·GitHub·Discord 구현을 유지합니다.
