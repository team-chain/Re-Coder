# ReCoder 1.1.4 — 통합 AI 대화와 초기 연결

## 사용

VSIX를 설치한 뒤 VS Code에서 **Developer: Reload Window**를 실행합니다. 실행 중이던 F5 개발 호스트가 있다면 종료하고 일반 VS Code에서 ReCoder를 엽니다.

- **코드 생성·수정**은 오른쪽의 공유 AI 대화를 엽니다. 질문, 개발 요청, 이어지는 수정 요청을 같은 입력창에 적습니다.
- 대화창에서 대상 폴더와 참고 파일을 선택합니다. 승인 시 선택한 참고 파일이 설계·생성 단계에도 전달됩니다.
- 중앙 **변경 내용**에서 설계 선택, 파일별 변경 보기, 개별 적용·모두 적용을 진행합니다. 승인 전에는 코드를 쓰지 않습니다.
- Develop·Deploy·Security를 이동해도 대화와 생성 결과가 유지됩니다. 좁은 화면에서는 설계 확인 시 대화창을 접어 검토 공간을 확보합니다.
- 시작 시 연결 확인이 자동으로 실행됩니다. AI 확인 중·준비됨·설정 필요·확인 실패를 구별하며, 실패하면 대화창의 **연결 다시 확인**을 사용할 수 있습니다.
- ReCoder 사이드바는 작업 화면을 여는 간단한 진입점입니다. 기존 Workbench와 배포 기능은 유지됩니다.

## 원인과 수정

동기 AI SDK와 Docker·AWS 진단이 Core의 비동기 요청 처리를 막을 수 있었습니다. 화면 초기화의 중복 진단 요청과 일반 작업 오류를 Core 연결 실패로 처리하는 표시 문제도 있었습니다. 진단 I/O를 별도 스레드로 옮기고, 진행 중인 연결·진단을 공유하며, 건강 상태와 진단 오류를 구별합니다. 대화·설계 요청은 초기 연결을 기다리되 전체 진단 완료를 기다리지 않습니다.

설계 요청에서 사용하지 않는 의존성 트리까지 전체 탐색·정렬하던 지연도 제거했습니다. 제외 폴더는 탐색 전에 걸러내고 80개 파일 상한에 도달하면 즉시 반환합니다.

## 검증

- 확장 회귀 테스트 385개 통과, 환경 조건 2개 건너뜀. 호스트·웹뷰 TypeScript 검사 및 프로덕션 빌드 통과.
- Core 관련 테스트 215개 통과, 플랫폼 조건 1개 건너뜀: 진단 동시 실행·취소·실패 재시도, 이벤트 루프 응답성, Gateway 진단, 참고 파일, 설계·ADR·코드 삭제 경고, 프로젝트 탐색 상한.
- 실제 웹뷰 + 컴파일된 확장 호스트 + 테스트 AI Core에서 요청 → 승인 → 설계 선택 → 파일·ADR 생성 → diff 요청 → 디스크 적용 확인.
- 대화·적용 결과의 탭 이동 유지, 단일 입력창, 768px 화면의 설계 카드와 취소 후 재입력 확인.
- 별도 HTTP 통합 하네스에서 워크스페이스 추가로 확장이 재시작될 때 승인 요청 인계와 중복 실행 방지 확인.
- 최종 VSIX의 네이티브 Core: Python 없는 PATH·격리된 사용자 폴더에서 기동, 세션 인증, AI 미설정 진단과 Core 정상 상태, 소스 분석, 미연결 AWS·미인증 GitHub 처리, 배포 계획·취소, 재시작·종료 통과.
- VSIX 내부 manifest·호스트·웹뷰·아이콘을 현재 빌드와 바이트 비교하고 Core·VSIX 해시 검증 통과.
