# ReCoder 학생 설치 가이드 (1장 요약)

> 준비물: VSCode, 운영자가 준 **`recoder-1.0.0.vsix`** 파일과 **반 코드(class code)**.
> AWS 키는 필요 없습니다. 운영자 계정으로 AI가 동작합니다.

## 1. 확장 설치
1. VSCode 왼쪽 **확장(Extensions)** 패널 열기 → 우상단 **`···`** → **Install from VSIX…**
2. 받은 `recoder-1.0.0.vsix` 선택 → 설치 후 VSCode **재시작(또는 창 새로고침)**
3. 왼쪽 활동바에 **ReCoder 아이콘**이 보이면 성공. (Core 엔진은 자동 실행됩니다 — 따로 켤 것 없음)

## 2. 최초 연결 (enroll)
- 설치 후 잠시 뒤 **반 코드 입력창**이 뜹니다 → 운영자가 알려준 코드 입력(예: `recoder2026`).
- 안 떴다면: `Ctrl+Shift+P` → **"ReCoder: Connect to Gateway (Enroll)"** 실행.
- "연결 완료" 알림이 뜨면 AI 사용 준비 끝.

## 3. 쓰는 법 — Build 탭
- **에러 수정(자동):** 터미널에서 코드를 실행하다 에러가 나면 ReCoder가 자동 감지해 수정안을 제안합니다. 수동으로는 에러 로그를 붙여넣고 **AI 분석**.
- **코드 생성:** "코드 생성" 칸에 자연어로 요청(예: `할 일 목록 앱 만들어줘, 추가/삭제/완료, localStorage 저장`) → **생성** → 만들어진 파일 카드에서 **적용**을 누르면 워크스페이스에 파일이 생기고 에디터가 열립니다.
  - ⚠ 표시가 뜨면 생성된 코드에 시크릿(키)이 섞였다는 경고입니다. 적용 전 확인하세요.

## 4. (선택) Discord 연동
운영자가 Discord를 사용할 때만 해당됩니다.
1. 워크벤치 **Discord 탭**에서 봇 초대 링크로 본인 서버에 봇 추가.
2. Discord 채널에서 **`/recoder link <내 student_id>`** 입력 — student_id는 enroll 완료 알림의 **'명령 복사'** 버튼으로 그대로 붙여넣으면 됩니다.
3. 이후 채널에서 **`/make 만들고 싶은 것`** 을 보내면 내 VSCode에 코드가 생성됩니다.

## 문제 해결
- **AI가 안 됨 / "게이트웨이 URL" 오류:** 운영자에게 올바른 VSIX를 받았는지 확인(주소가 안 박힌 구버전일 수 있음).
- **"Core not ready":** 1–2분 기다리거나 `Ctrl+Shift+P` → **ReCoder: Restart Core**.
- **반 코드 거부:** 코드 오타 또는 등록 정원 초과 — 운영자에게 문의.
