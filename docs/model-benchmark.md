# ReCoder 모델별 비용 · 시간 측정

ReCoder로 앱을 만들 때 AI 모델과 모드(품질 우선 / 균형 / 비용 절약)에 따라 비용과 시간이 얼마나 달라지는지 정리한 문서입니다.

- 기준 버전: ReCoder 4.0.1
- 측정 기간: 2026-10-17 ~ 2026-11-22
- 측정 대상: 개발 PC에서 ReCoder가 실제로 보낸 AI 호출 715건

> **읽기 전에.** 이 문서의 숫자는 두 종류입니다.
> **실측**은 ReCoder가 기록한 실제 호출에서 나온 값이고, **추정**은 그 실측값에 공식 단가와 가정을 곱해 계산한 값입니다.
> 표마다 어느 쪽인지 적어 두었습니다. 추정값은 직접 측정한 결과가 아닙니다.

## 2. 모드가 하는 일

ReCoder는 코드를 만들 때 AI에게 네 가지 역할을 나눠 맡깁니다. 모드는 역할마다 **품질 모델**을 쓸지 **빠른 모델**을 쓸지를 정합니다.

| 모드 | 설계 | 개발 | 검토 | 테스트 |
|---|---|---|---|---|
| 품질 우선 | 품질 | 품질 | 품질 | 품질 |
| 균형 (기본값) | 품질 | 품질 | 빠른 | 빠른 |
| 비용 절약 | 빠른 | 빠른 | 빠른 | 빠른 |

근거: `extension/webview-src/components/teamConfig.ts`

품질 모델과 빠른 모델에 어떤 모델을 넣을지는 사용자가 설정에서 고릅니다. 고르지 않았을 때의 기본값은 아래와 같습니다.

| 공급자 | 품질 모델 | 빠른 모델 |
|---|---|---|
| Claude | Claude Sonnet 5.5 | Claude Haiku 5.5 |
| GPT | GPT-6 Sol | GPT-6 Sol (같은 모델) |

근거: `core/llm/api_key_provider.py`

### 모드와 상관없이 지켜지는 안전장치

| 안전장치 | 내용 |
|---|---|
| 보안 수정 · 교정 | 어떤 모드에서도 품질 모델이 맡습니다. 끌 수 없습니다. |
| 민감한 요청 | 로그인, 회원가입, 결제, 개인정보가 들어간 요청은 설계와 개발을 품질 모델로 고정합니다. |
| 실패 시 재생성 | 빠른 모델의 결과가 빌드나 보안 검사에서 실패하면 품질 모델로 한 번 다시 만듭니다. |

근거: `core/llm/task_tier.py`

## 3. 측정 방법

### 무엇을 기록하나

ReCoder는 AI를 부를 때마다 호출 한 건을 원장 파일(`~/.recoder/model_costs.jsonl`)에 한 줄씩 남깁니다. 프롬프트와 생성된 코드는 남기지 않습니다.

| 기록 항목 | 설명 |
|---|---|
| 작업 이름 | 설계, 코드 생성, 교정, 테스트 초안 등 어떤 일이었는지 |
| 모델 | 실제로 응답한 모델 |
| 입력 · 출력 토큰 | 715건 중 625건은 API가 돌려준 실제 값, 90건은 글자 수로 어림한 값 |
| 응답 시간 | 요청을 보낸 순간부터 응답이 끝날 때까지 |
| 재시도 · 대체 여부 | 다른 모델로 넘어갔는지 |

### 측정 기준

- **비용**은 원장의 토큰 수에 각 회사의 공식 목록 단가를 곱해 다시 계산했습니다. 앱 화면에 보이는 금액은 일부 호출에 예전 어림 단가가 적용되어 이 문서의 값과 다를 수 있습니다.
- **시간**은 한 번의 생성 작업에서 첫 호출부터 마지막 호출까지 걸린 시간입니다. 호출 사이 간격이 15분을 넘으면 다른 작업으로 나눴습니다. 개발 역할은 여러 호출이 동시에 나가므로, 호출별 응답 시간의 합보다 짧습니다.
- **단가** (백만 토큰당 입력 / 출력, 2026-11-22 확인)

| 모델 | 입력 | 출력 | 출처 |
|---|---|---|---|
| Claude Opus 5.5 | $4 | $20 | Anthropic 공식 가격표 |
| Claude Sonnet 5.5 | $2 | $10 | Anthropic 공식 가격표 |
| Claude Haiku 5.5 | $0.10 | $0.50 | Anthropic 공식 가격표 (요청이 10만 토큰을 넘으면 5배) |
| Claude Haiku 4.5 | $1 | $5 | Anthropic 공식 가격표 |
| GPT-6 Sol · GPT-6.1 Sol | $2 | $10 | 가격 정리 사이트 2곳 (OpenAI 공식 페이지 미확인) |
| GPT-6.1 Terra | $1 | $5 | 가격 정리 사이트 |

## 5. 모델 조합별 추정

> **이 절의 숫자는 모두 추정입니다.** 실제로 각 조합을 돌려서 잰 값이 아닙니다.

### 계산 방법

1. 기준 작업은 4절의 11-15 작업입니다 (Opus 5.5, 15.2분, 입력 144만 · 출력 21만 토큰).
2. 이 작업의 토큰을 4절의 역할별 비중으로 나눕니다.
3. 모드에 따라 역할마다 모델을 배정하고, 그 모델의 공식 단가를 곱합니다.
4. 보안 수정 · 교정은 항상 품질 모델로 계산합니다.
5. 균형과 비용 절약 모드에는 "실패 시 품질 모델로 재생성"하는 비용과 시간을 더합니다.

### 가정한 값

아래 두 값은 측정하지 않고 가정했습니다. 결과는 이 가정에 따라 달라집니다.

| 가정 | 내용 |
|---|---|
| 모델별 속도 | Opus 5.5를 1로 두고 Sonnet 5.5 1.45배, GPT Sol 1.35배, GPT-6.1 Terra 1.8배, Haiku 5.5 2.4배, GPT-6 Luna 2.5배 |
| 재생성 비율 | 빠른 모델일수록 빌드 · 보안 검사에서 실패해 다시 만드는 비율이 높다고 가정 (Sonnet 5.5 11%, Haiku 5.5 32% 등) |

코드 품질은 이 문서에서 수치로 제시하지 않습니다. 모델별 품질은 같은 요청을 실제로 돌려 봐야 알 수 있습니다 (6절).

## 6. 한계와 직접 측정하는 방법

### 이 문서의 한계

- 실측 작업들은 요청이 서로 달라, 모델끼리 같은 조건으로 비교한 것이 아닙니다.
- 실측 기간 동안 ReCoder 버전이 여러 번 바뀌었습니다.
- 코드 품질(빌드 성공, 교정 횟수, 보안 점수)은 원장에 남지 않아 이 문서에 없습니다.

### 직접 측정하기

ReCoder에는 같은 요청을 두 모델로 돌려 비교하는 기능이 있습니다.

1. Develop 탭의 「AI 모델 · 비용」을 엽니다.
2. 「같은 요청을 두 모델로 비교」를 누르고 요청을 입력합니다.
3. 비교할 두 모델을 고르고 시작합니다.

이 기능은 두 모델의 비용, 토큰, 교정 횟수, 남은 오류 수, 보안 점수를 나란히 보여 줍니다. 파일은 바꾸지 않으며, AI 요금은 두 번 듭니다. 한 번에 고를 수 있는 것은 지금 설정된 공급자의 모델들입니다.

근거: `core/model_compare.py`

### 품질이 높은 순 (모델 등급 기준)

품질은 이 문서에서 측정하지 않았습니다. 아래 순위는 **코드를 쓰는 역할(설계 · 개발)에 각 회사의 어느 등급 모델이 들어가는지**로 매겼습니다. 같은 회사 안에서는 상위 등급 모델이 더 많은 일을 맡을수록 위에 둡니다. 회사가 다른 같은 등급 모델끼리는 우열을 가릴 근거가 없어 같은 순위로 둡니다.

| 순위 | 조합 | 모드 | 설계 · 개발 모델 | 검토 · 테스트 모델 | 비용 | 시간 |
|---|---|---|---|---|---|---|
| 1 | Claude Opus 5.5 | 품질 우선 | 최상위 | 최상위 | $10.04 | 15.2분 |
| 2 | Claude Opus 5.5 + Sonnet 5.5 | 균형 | 최상위 | 상위 | $9.48 | 14.6분 |
| 3 | Claude Opus 5.5 + Haiku 5.5 | 균형 | 최상위 | 경량 | $8.73 | 13.8분 |
| 공동 4 | Claude Sonnet 5.5 | 품질 우선 | 상위 | 상위 | $5.02 | 10.5분 |
| 공동 4 | GPT-6.1 Sol · GPT-6 Sol | 품질 우선 | 상위 | 상위 | $5.02 | 11.3분 |

### 정리

- **비용과 시간**은 거의 같은 조합이 상위를 차지합니다. 경량 모델이 모든 역할을 맡는 조합입니다.
- **품질** 상위 조합은 비용과 시간 순위에 하나도 들지 않습니다. 세 기준을 모두 1위로 만족하는 조합은 없습니다.
- 기본값인 **균형 모드(Claude Sonnet 5.5 + Haiku 5.5, $4.70, 10.6분)** 는 코드를 쓰는 역할에 상위 모델을 유지하면서, 최상위 조합 대비 비용을 절반 이하로 낮춥니다.
- 비용 절약 모드에서도 보안 수정 · 교정은 품질 모델이 맡으므로, 가장 싼 조합도 안전장치는 그대로 적용됩니다.
