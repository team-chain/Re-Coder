# Changelog

## 1.0.0 — 2026-09-19 (마켓플레이스 첫 게시 후보)

### 추가
- AI-DLC 설계 결정 카드: 코드 생성 전에 구조에 영향 주는 선택을 사람이 고른다.
- 워크스페이스 허브(Develop · Deploy · Security)와 채팅 승인 카드 흐름.
- S3 정적 사이트 배포 — 진행 상황을 SSE 로 실시간 표시.
- ECS 배포·감시·롤백 제안→승인 흐름.
- AWS 원클릭 IAM 셋업 — 최소권한 사용자·키를 CloudFormation 으로 생성.
- 구조 지도(CodeMap): 프로젝트 import 그래프와 파일 내부 호출 그래프, 고립·과부하 진단.

### 안전장치
- 보안 스캔 미실행은 "통과"가 아니라 "확인 못 함"으로 표시하고 승인 강도를 올림.
- 빌드 전 이미지를 Trivy 에 넘기지 않음 — 실행 시점(빌드 후) 1회 스캔 보장, CRITICAL 차단.
- 배포 허용 조건은 OPA 정책(.rego) 한 곳에 선언 — 판정 불능이면 차단(fail-closed).
- 에이전트 로드 실패가 200 OK 로 위장되던 응답 제거(503 + 사유).
- LLM 라우터 단일화 — 서킷브레이커·게이트웨이·비용 집계가 전 경로에 적용.

### 수정
- 로컬 배포 컨테이너 이름에 이미지 태그가 들어가 400 나던 문제.
- 순수 파이썬 프로젝트가 python-fastapi 로 오분류되어 컨테이너가 즉사하던 문제.
- 워크벤치 사이드바 버튼 무반응(핸들러 공통 호스트로 통합).
- 코어에 라우트가 없는 EC2 배포 UI 제거(404 방지).
