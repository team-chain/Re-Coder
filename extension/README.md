# ReCoder — AI DevOps Agent

> 채팅으로 요청하면 **설계 선택지**를 먼저 제시하고, 사람이 고른 결정에 따라 코드를 만들고,
> 그 결정을 ADR로 남기고, 배포·감시·롤백까지 한 흐름으로 이어주는 VS Code 확장.

AI가 혼자 판단해 코드를 쏟아내지 않습니다. 갈림길이 있으면 **선택지 카드**를 띄우고,
사람이 승인한 뒤에만 진행합니다. 무엇을 왜 그렇게 정했는지는 `docs/adr/` 에 기록으로 남습니다.

## 무엇을 하나

| | |
|---|---|
| **설계 결정 먼저** | "할 일 앱 만들어줘" → 코드 대신 "데이터를 어디에 저장할까요?" 같은 선택지 카드. 고른 뒤에 코드가 나옵니다. |
| **결정 기록 (ADR)** | 승인된 선택은 `docs/adr/ADR-NNN-*.md` 로 자동 기록됩니다. 결정·근거·검토한 대안·영향 네 항목. |
| **에러 분석과 패치** | 터미널 출력을 읽어 원인을 찾고 수정안을 제시합니다. 적용 전 diff 확인, 적용 후 롤백 가능. |
| **인프라 파일 생성** | Dockerfile · docker-compose · GitHub Actions 초안을 프로젝트 구조에 맞춰 만듭니다. |
| **배포 전 검사** | 환경변수 누락, 포트, 시크릿 유출, 이미지 취약점을 배포 전에 걸러냅니다. |
| **배포** | 정적 사이트는 본인 AWS 계정 S3로, 컨테이너 앱은 ECS로. 자격증명은 로컬에만 저장됩니다. |
| **감시와 롤백** | 배포 후 health·에러율·메모리를 추적하다 이상하면 롤백을 제안합니다. |

모든 실행 단계에 **사람 승인**이 걸려 있습니다. 확장이 사용자 모르게 파일을 고치거나 배포하지 않습니다.

## 설치

1. VSIX 파일을 받습니다.
2. VS Code → 확장 → `...` → **Install from VSIX...**
3. 사이드바의 ReCoder 아이콘을 엽니다.

Local Core는 확장에 동봉된 바이너리로 자동 실행됩니다. Python 설치나 별도 명령이 필요 없습니다.

## AI 연결 — 두 가지 방법

**게이트웨이 (권장, AWS 계정 불필요)**
운영자가 배포한 게이트웨이를 통해 모델을 씁니다. 명령 팔레트 → `ReCoder: Connect to Gateway (Enroll)` →
받은 코드를 입력하면 끝입니다.

**본인 AWS 계정 (BYO)**
사이드바의 AWS 연결에서 액세스 키를 등록합니다. 키는 `~/.recoder/` 에 0600 권한으로만 저장되고
외부로 나가지 않습니다. 필요한 최소 권한 정책은 확장이 만들어 보여줍니다.

## 요구 사항

- VS Code 1.85 이상
- 배포 기능을 쓰려면 Docker Desktop (정적 사이트 배포는 불필요)
- ECS·EKS 배포를 쓰려면 본인 AWS 계정

## 알아두실 것

- 확장에 동봉된 Core 바이너리는 **OS별로 다른 파일**입니다. 본인 OS용 VSIX를 설치하세요.
- AWS 배포는 본인 계정에 실제 리소스를 만듭니다. 요금이 발생할 수 있으니
  배포 전 예산 알림을 걸어두시길 권합니다.
- AI가 만든 코드와 인프라 파일은 **초안**입니다. 적용 전에 확인하세요.
  확장이 승인 단계를 두는 이유가 그것입니다.
